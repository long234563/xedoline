# Shadow Ronin - Android Prototype V1

Game đối kháng 2D offline chạy trong Android WebView.

## Điều khiển
- Trái/phải: di chuyển
- Lên: nhảy
- Xuống: ngồi
- Đấm / Đá / Kiếm katana / Phi tiêu / Skill / Đỡ
- PC test: A/D/W/S, J/K/L, U (phi tiêu), I (skill), Shift (đỡ)

## Build
GitHub Actions workflow `.github/workflows/build-apk.yml` build APK debug.
